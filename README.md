# Open environ

Open environ is a gamified learning platform that makes forest conservation education engaging and social. Learners can explore content, grow their progress, connect with friends, and compare progress on a leaderboard.

## Features

- Account creation, sign-in, email verification, and password reset
- Protected dashboard, profile, settings, tutorial, and about pages
- Friends and leaderboard features
- PostgreSQL persistence through Drizzle ORM
- Email delivery through SMTP

## Tech stack

- Next.js 16 and React 19
- TypeScript and Mantine UI
- PostgreSQL and Drizzle ORM
- Better Auth
- oRPC and TanStack Query
- Biome
